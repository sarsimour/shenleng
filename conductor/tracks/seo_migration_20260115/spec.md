# 需求规范：SEO 优化与旧站迁移保障

## 1. 概述
本 Track 的重点是针对中国搜索引擎市场（特别是百度）优化 Next.js 应用，并通过 Nginx 重定向确保从旧网站 (`http://www.sl-cold.com`) 迁移后的链接权重得以保留。同时，我们将建立符合 2025/2026 年百度 SEO 趋势的高性能标准（极速首屏、移动优先）。

## 2. 功能需求

### 2.1 百度 SEO 优化（核心）
- **全局 Meta 标签**：实现标准的 Meta 标签（标题、描述、关键词），并侧重于百度的偏好。
- **百度专用标签**：
    - 添加百度站点验证标签 (`baidu-site-verification`)。
    - 添加移动端适配标签（例如：`meta name="applicable-device" content="pc,mobile"`）。
- **Robots.txt**：创建符合百度爬虫 (`Baiduspider`) 规范的 `public/robots.txt`。
- **站点地图 (Sitemap)**：生成包含所有静态页面 and 动态文章页面的 `sitemap.xml`，格式符合百度搜索资源平台的要求。
- **结构化数据 (JSON-LD)**：
    - **企业信息**：包含公司名称、地址、联系方式、Logo。
    - **文章**：包含标题、发布时间、**最后修改时间**（针对旧文章优化）、作者。
- **备案信息展示**：确保页脚清晰展示 ICP 备案号和公安联网备案号（硬性要求）。

### 2.2 性能与移动优先（关键指标）
- **SSG 静态生成**：确保首页、关于页、所有文章详情页在构建时生成纯静态 HTML 文件。
- **首屏加载优化**：
    - 目标：移动端首屏内容渲染 (FCP) < 1.5秒。
    - 图片优化：强制使用 Next/Image 转换为 WebP 格式。
    - 资源屏蔽：严禁引入 Google Fonts/APIs 等可能在中国超时的外部资源。

### 2.3 旧链接保留 (Nginx)
- **映射策略**：
    - **主要来源**：从 Payload CMS 内容（或原始 JSON）中提取“原始链接”。
    - **次要来源**：爬取 `sl-cold.com` 获取遗漏链接。
- **Nginx 配置**：
    - 生成 Nginx 301 重定向规则。
    - 适配当前 `www.finverse.top` 测试域名，并支持未来切换回主域名。

### 2.4 SEO 长期策略建议文档
- 创建文档 `docs/high_priority_seo_strategy.md`，记录关于“内容生态闭环（百家号/小程序）”及“持续内容更新”的专家建议，供后续运营参考。

## 3. 非功能需求
- **验证机制**：编写自动化测试脚本，验证旧 URL 的 301 重定向状态。

## 4. 验收标准
- [ ] `robots.txt` 和 `sitemap.xml` 可访问且格式正确。
- [ ] 页面源代码中包含正确的百度 Meta 标签和 JSON-LD 数据。
- [ ] **构建验证**：确认核心页面已生成静态 HTML 文件 (SSG)。
- [ ] **性能验证**：Lighthouse 移动端性能评分 > 90（或 FCP < 1.5s）。
- [ ] 自动化脚本验证重定向规则有效。
- [ ] 产出 `docs/high_priority_seo_strategy.md` 文档。
