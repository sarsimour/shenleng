# 申冷物流：2025/2026 百度 SEO 核心策略建议 (高优先级)

## 1. 核心趋势：从“网站 SEO”转向“生态 SEO”
百度当前的流量分发逻辑已经发生了根本变化。单纯依靠官网收录已不足够，必须建立“内容生态闭环”。

### 1.1 百家号 (BJH) 联动
*   **策略**：在新网站发布文章后，**同步发布**到百家号。
*   **优势**：百家号内容在百度搜索中拥有极高的权重，往往能排在官网之前。
*   **行动项**：
    *   注册企业认证的百家号。
    *   在百家号文章中挂载“申冷物流官网”的小程序或直接链接。

### 1.2 移动端优先与小程序
*   **现状**：百度搜索 80% 以上流量来自移动端。百度对原生 HTML5 站点的抓取虽好，但对“百度小程序”有额外的流量倾斜。
*   **建议**：在官网稳定运行后，考虑将 Next.js 的内容通过 API 接入百度小程序。

## 2. 权威性与信任度 (E-A-T)
物流行业属于“要钱要命”的 B2B 决策。百度通过以下信号判断网站是否可信：

*   **备案一致性**：确保页脚显示的 ICP 备案号与工信部查询结果完全一致。
*   **结构化数据 (JSON-LD)**：我们已在代码中实现，务必确保 `Organization` 数据中的电话、地址与“联系我们”页面完全一致。
*   **HTTPS 强制**：全站强制 HTTPS。

## 3. 内容更新与时效性
百度严厉打击“静态死站”。

*   **更新频率**：建议**每周至少更新 1 篇**行业洞察或公司动态。
*   **旧内容优化**：对于迁移过来的旧文章（如 2021 年的内容），我们在页面上增加了 `dateModified` 字段。如果内容仍有价值，建议小幅度修改文字后重新发布，以触发百度的“时效性”抓取。

## 4. 极速首屏 (Speed is Content)
*   **性能指标**：移动端 FCP (First Contentful Paint) 必须控制在 **1.5秒** 以内。
*   **禁忌**：严禁引入任何未在中国 CDN 加速的 JS 库、字体库（如 Google Fonts）或外部 API，这些会导致百度爬虫超时而放弃抓取。
